# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Char Factory opens files downloaded from the internet (characters, archives, stages), so problems
such as a crafted `.sff`, `.zip` or `.def` that writes outside the target folder or runs code are
taken seriously.

Please **do not** open a public issue. Use
[private vulnerability reporting](../../security/advisories/new) on GitHub instead, with:

- what the problem is and what an attacker could do with it;
- the steps or a sample file that reproduces it;
- the version (or commit) you tested.

You should get an answer within a week. Once a fix is released, the advisory is published with
credit to the reporter, unless they prefer to stay anonymous.
